Praus Office Automation

프라우스투자일임이 사내 업무 자동화에 쓰는 개인용 프로그램입니다. 회사 대표 한 사람의 구글 계정만 연결하며, 다른 사람의 계정이나 정보를 다루지 않습니다.

An internal automation tool used by Praus Investment. It connects only to the company owner's own Google account and does not access anyone else's account or data.

하는 일 · What it does

  • 구글 할 일(Google Tasks) — 대표가 휴대전화에 적은 할 일을 읽어 사내 업무 목록에 옮기고, 끝난 일에 완료 표시를 합니다.
    Reads the owner's Google Tasks to add them to an internal to-do list, and marks finished tasks as completed.
  • 구글 드라이브(drive.file) — 드라이브 저장 공간이 얼마나 찼는지 확인합니다. 이 프로그램이 만든 파일 말고는 열지 않습니다.
    Checks how much Google Drive storage is used. It cannot open files it did not create.
  • 유튜브(YouTube) — 회사 채널에 회사가 만든 분석 영상을 올리고, 제목·설명·자막·썸네일·공개 시각·재생목록을 관리합니다. 회사 채널의 조회수 통계를 읽어 사내 보고에 씁니다.
    Uploads the company's own analysis videos to the company's own channel and manages their titles, descriptions, captions, thumbnails, release times and playlists. Reads the channel's own view statistics for internal reporting.

개인정보처리방침 · Privacy Policy

  1. 무엇을 읽는가 — 위 세 가지에 필요한 정보만 읽습니다: 대표 계정의 할 일 제목·마감일·완료 여부, 드라이브 사용량, 회사 유튜브 채널의 영상·재생목록과 조회수 통계.
    Data accessed: only what the three functions above need — task titles, due dates and status; Drive storage usage; the company channel's own videos, playlists and view statistics.
  2. 어디에 두는가 — 회사가 관리하는 컴퓨터 안에만 둡니다. 구글이 준 연결 열쇠도 그 컴퓨터에만 있습니다.
    Storage: data and access tokens stay on a company-managed computer.
  3. 누구에게 주는가 — 누구에게도 팔거나 넘기지 않습니다. 광고에 쓰지 않습니다.
    Sharing: never sold or shared with anyone, never used for advertising.
  4. 구글 정보 사용 기준 — 구글 API에서 받은 정보는 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
    Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  5. 끊는 법 — 대표는 언제든 구글 계정 › 보안 › 서드 파티 연결에서 연결을 끊을 수 있고, 그러면 프로그램은 더 읽지 못합니다.
    Revoking: access can be removed at any time from Google Account › Security › Third-party connections.
